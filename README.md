# 🎥 Claude Video Skills — banque de skills vidéo pour Claude

Collection de **323 skills Claude** (format `SKILL.md` / Agent Skills) dédiées à la vidéo, récupérées depuis **47 dépôts open source** sur GitHub : montage FFmpeg, Remotion, HyperFrames, Manim, motion design, génération vidéo IA, YouTube/TikTok, sous-titres, voix-off…

> ⚠️ Chaque skill garde la licence de son dépôt d'origine (fichiers `_LICENSE*` et `_SOURCE.md` dans chaque dossier source). Lisez le `SKILL.md` et les scripts avant d'installer : certaines skills appellent des API payantes (fal.ai, ElevenLabs, Higgsfield, BytePlus…) ou des outils externes (ffmpeg, yt-dlp, whisper, Node.js). Les fichiers média lourds (>3 Mo, mp4/gif/wav…) ont été retirés.

## 🚀 Installation

Copier une skill dans votre dossier de skills Claude Code (perso ou projet) :

```bash
cp -r skills/remotion-dev__skills/remotion-best-practices ~/.claude/skills/
```

Ou tout un dépôt source :

```bash
cp -r skills/louisedesadeleer__clipify/* ~/.claude/skills/
```

Pour Claude.ai / Claude Desktop : zippez le dossier de la skill et importez-le dans *Settings → Capabilities → Skills*.

Le fichier [`index.json`](index.json) liste toutes les skills (nom, description, dépôt, commit, chemin).

## 📁 Structure

```
skills/<owner>__<repo>/<skill>/SKILL.md   # skills, groupées par dépôt d'origine
harnesses/youtube-production/            # équipe d'agents complète (revfactory/harness-100)
references/                              # listes & README de référence (toolkits, packs iart-ai)
index.json                               # catalogue machine-readable
```
